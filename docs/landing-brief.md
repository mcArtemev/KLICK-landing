# Klick landing — продуктовый и контентный бриф

## Позиционирование первой версии

Klick — единое рабочее пространство для частных репетиторов и онлайн-преподавателей. Главная ценность — не количество функций само по себе, а связный рабочий цикл: расписание → урок → практика → проверка → прогресс → оплата.

Главное сообщение: **«Преподавание — в один клик»**.

Основная аудитория первой версии: самостоятельный преподаватель с несколькими учениками, которому уже тесно в комбинации календаря, мессенджеров, облачных папок и таблиц. Школьные CRM-сценарии (воронка продаж, филиалы, сотрудники, зарплаты) сознательно не заявлены, потому что продукт пока сфокусирован на преподавателе и ученике.

## Принципы дизайна

1. За несколько секунд понятно, для кого Klick и какую проблему он решает.
2. Вместо стоковых фотографий используется интерфейс продукта — он одновременно объясняет ценность и формирует доверие.
3. Одна основная CTA формулировка: «Открыть Klick» / «Начать работу».
4. Тексты короткие и сканируемые; каждый экран отвечает на один вопрос.
5. Визуальная система продолжает продукт: Inter, тёплый фон, stone-палитра, янтарный акцент, мягкие тени, радиусы 16–24 px.
6. Анимации только поддерживают восприятие и отключаются через `prefers-reduced-motion`.
7. Нет неподтверждённых цифр, логотипов клиентов, отзывов и обещаний бесплатного тарифа.

Основа по UX: [NN/g — Homepage Usability](https://www.nngroup.com/articles/113-design-guidelines-homepage-usability/) и [web.dev — Web performance](https://web.dev/performance/).

## Структура первой версии

1. Первый экран: аудитория, ценность, CTA и продуктовый интерфейс.
2. Контраст «разрозненные инструменты → одно пространство».
3. Четыре главных сценария: календарь, задания, учебный план, профиль ученика.
4. Вторичные возможности: тесты, материалы, оплаты, уведомления.
5. Сквозной рабочий процесс преподавателя.
6. Отдельная ценность личного кабинета ученика.
7. Продуктовые принципы и финальная CTA.

## Материалы для следующей итерации

- URL рабочего приложения для `VITE_APP_URL`.
- Подтверждённые условия тарифа или пробного периода.
- 2–3 настоящих отзыва первых преподавателей с именем и разрешением на публикацию.
- Проверяемая продуктовая метрика: сэкономленное время, доля сданных вовремя заданий или число активных преподавателей.
- Юридические страницы: политика конфиденциальности, оферта и контакты компании.
- Реальные скриншоты после стабилизации данных и финального визуального QA продукта.
